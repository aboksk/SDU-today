# SDU Today — правила проекта

- `sdu-today/` и `legacy-prototype/` — статический учебный прототип; не удалять и не переносить его логику без отдельной задачи.
- `apps/api/` — REST API на NestJS; схема БД, миграции и начальные данные находятся в `apps/api/prisma/`.
- `apps/web/` — заготовка для будущего React-клиента.
- Запросы к PostgreSQL выполнять через Prisma. Изменения схемы оформлять миграциями.
- Переводимые тексты хранить в JSON с ключами `ru` и `en`.
- Не добавлять зависимости и инфраструктуру, не нужные для текущего этапа.
- Запуск и команды описывать в корневом `README.md`; архитектурные решения записывать в `docs/DECISIONS.md`.
