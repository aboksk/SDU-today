# SDU Today (прототип)

Запуск: откройте `index.html` в браузере (нужен интернет для шрифтов и QR-библиотеки).

Файлы:
- `index.html`: каркас страницы
- `style.css`: стили и цвета (переменные в начале файла)
- `app.js`: данные (новости, мероприятия, места на карте), страницы и логика
- `assets/`: логотип и план кампуса

Где что менять в app.js:
- `BASE_EVENTS`: мероприятия
- `NEWS`: новости
- `place(...)`: места на карте (координаты x, y на изображении 1382x2576)
- `WINGS`, `TOPX`, `BOTX`: координаты кабинетов; аудитории генерируются для этажей 1–3, этаж выбирается на карте
- `TX`: тексты интерфейса на русском и английском
